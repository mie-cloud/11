Python基础 - 变量与数据类型

变量

在Python中，变量是用来存储数据的容器。变量的赋值使用等号（=）。 

# 变量赋值
name = "John"
age = 30

数据类型

Python有多种内置数据类型，包括：

  • 整数（int）：如 1, 2, 3
  • 浮点数（float）：如 1.5, 2.0
  • 字符串（str）：如 "Hello"
  • 布尔值（bool）：True 或 False
  • 列表（list）：如 [1, 2, 3]
  • 元组（tuple）：如 (1, 2, 3)
  • 字典（dict）：如 {"name": "John", "age": 30}
